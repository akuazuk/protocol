Обработка документов (B2C)

Загруженные фото и PDF используются только для одной автоматической сверки с клиническими протоколами Минздрава РБ. После формирования ответа содержимое не сохраняется на сервере Protocol.

История на устройстве (localStorage/sessionStorage) хранит дату, краткий итог и чек-лист — только локально. Кнопка «Удалить данные на устройстве» очищает эти записи.

Обезличенные события (открытие отчёта, share) могут логироваться без текста КЗ для улучшения сервиса.
