## 1. Паспорт инновационного проекта (форма)

### 1. Наименование

**Protocol** - программный модуль предимпортной экспертизы консультативных заключений по клиническим протоколам Минздрава РБ и готовности пакета FHIR BY к ЦИСЗ (интеграция с МИС «Айболит»).

### 2. Краткое описание (до 2000 знаков)

В Республике Беларусь действует порядка **478** официальных клинических протоколов Минздрава; частная амбулатория обязана вести консультативные заключения (КЗ) по стандартам и передавать данные в государственный контур ЦИСЗ в формате FHIR BY. Врач физически не может держать в памяти все протоколы; методслужба не успевает проверять каждое КЗ до подписи ЭЦП. Ошибки оформления и клинические пробелы приводят к отклонению пакетов в ЦИСЗ и репутационным рискам перед Минздравом.

**Protocol** - отечественный программный продукт, разработанный на площадке МЦ «Кравира»: (1) подбор релевантных клинических протоколов по МКБ-10 и тексту КЗ; (2) **детерминированная** оценка соответствия КЗ протоколам (8 блоков, карта доказательств, 482+ правил) с прозрачными цитатами из официальных PDF; (3) чек-лист готовности к ЦИСЗ (программа испытаний МИС v.1.3-4, протокол взаимодействия v.1.4); (4) единое решение о подписи `send_gate` для МИС. Языковая модель используется только для пояснений; **блокировка и итоговый балл для МИС считаются по правилам**, не «на глаз» у нейросети.

На пилотной площадке развёрнут рабочий прототип (веб-интерфейс + API, уровни L0-L2). Планируется встраивание в МИС «Айболит» (EPAM): вызов L0 при каждом сохранении КЗ (&lt;2 с), полный разбор L2 по запросу методслужбы. Продукт не заменяет врача, МЭЭ и серверную валидацию ЦИСЗ - снижает долю слабых КЗ **до** отправки в государственный реестр.

Корпус: ~105 000 фрагментов из PDF Минздрава, 24 рубрики, справочник МКБ-10. Развёртывание - в защищённом контуре РБ (см. `docs/deployment-belarus.md`).

### 3. Направление применения (не более 2)

- **Медицинские науки и технологии**
- **Информатика, информатизация и космические исследования**

### 4. Новизна

**Нет аналогов в стране, есть за рубежом.**

Пояснение: зарубежные CDSS и LLM-сервисы не содержат корпуса клинических протоколов Минздрава РБ, профилей FHIR BY и чек-листа ЦИСЗ 3.2.1 в одном контуре. В РБ нет готового B2B-продукта «КП Минздрава + предпроверка Bundle до ЭЦП» для частных ОЗ.

### 5. Стадия

**Работающий прототип** → переход к **опытному образцу** (пилот в Кравире, интеграция L0 в МИС).

### 6. Потенциальные потребители (до 500 знаков)

B2B: частные ОЗ, сети, МИС (Айболит), методслужбы; якорь - Кравира (~25 000 КЗ/мес). B2C: физические лица - пациенты, проверяющие своё КЗ и качество услуги по протоколам Минздрава (веб, QR от клиники).

### 7. Конкурентные преимущества (до 500 знаков)

1. **Официальный корпус КП Минздрава** (~478 PDF) с цитатами в отчёте, а не «общие рекомендации ИИ».  
2. **Детерминированный scoring** (8 блоков, `gate_score`, `soft_gate`) - воспроизводимость и доверие методслужбы.  
3. **Два контура:** клиника (протоколы) + ЦИСЗ (FHIR BY) в одном `send_gate`.  
4. **Tiering L0/L1/L2** - массовая проверка за &lt;2 с без LLM (L0) для каждого КЗ.  
5. **Пилот на реальном потоке** Кравиры (~25 000 КЗ/мес).  
6. **Готовность к on-prem** в контуре РБ, ключ и ПДн на стороне заказчика.  
7. **B2C для пациентов** - отдельный канал дохода и социальный эффект (прозрачность помощи).

## 2. Резюме бизнес-плана (раздел 3 формы БП)

**Идея.** Монетизировать массовую **предимпортную проверку КЗ** для частных медцентров РБ по модели **микроплатежа за проверку** (от **0,99 BYN** за одно КЗ на уровне L0) с **пакетными скидками** для крупных потоков, плюс внедрение API в МИС.

**Проблема.** ~2,5 млн КЗ/мес в сегменте платных услуг частных ОЗ РБ (25 000 КЗ/мес в Кравире = 1% рынка); доля отклонений и доработок в ЦИСЗ; нагрузка на методслужбу.

**Решение.** Protocol автоматизирует проверку до ЭЦП: клинические протоколы + FHIR/ЦИСЗ, решение `send_gate`.

**Рынок.** Частная амбулатория РБ; МЦ «Кравира» - **25 000** КЗ/мес (**1%** платных КЗ частного сектора). Потенциал сегмента: **2 500 000** КЗ/мес (**30 млн**/год).

**Монетизация (базовый сценарий).**

| Тариф | Цена | Кому |
|-------|------|------|
| L0 «за КЗ» | **0,99 BYN**/проверка | малые клиники, pay-as-you-go |
| Пакет 10 000 КЗ/мес | **0,79 BYN**/КЗ | средние ОЗ |
| Пакет 25 000+ КЗ/мес | **0,69 BYN**/КЗ | Кравира, сети |
| L2 + методист | **+0,50 BYN**/КЗ или абонент | углублённый разбор с LLM |
| Внедрение API в МИС | **разово 15-40 тыс. BYN** + поддержка | партнёры-вендоры |
| **B2C «Базовая»** | **4,99 BYN**/КЗ | физлицо, L1 |
| **B2C «Подробный»** | **9,99 BYN**/КЗ | физлицо, L2 + пояснения |
| **B2C абонемент** | **12,99 BYN**/мес (3 проверки) | активные пользователи |

**Кравира (якорный клиент):** 25 000 × 0,69 = **17 250 BYN/мес** (~**207 тыс. BYN/год**) при полном покрытии L0.

**Запрос.** Премия / **сертификат ГКНТ (571 б.в.)** на: доработку интеграции МИС, on-prem развёртывание, сертификацию ПО, маркетинг в 5-10 частных ОЗ.

**Ключевые показатели (год 3, осторожный сценарий):** 8% рынка (200 000 КЗ/мес) × 0,75 BYN ср. чек ≈ **150 000 BYN/мес** B2B; совокупная выручка **~2,33 млн BYN/год**; EBITDA **+1,68 млн**; точка безубыточности направления - **2-3** клиники уровня «Клиника» (10k КЗ) или OEM API МИС.

## 3. Бизнес-план - развёрнутые черновики разделов

### 4. Описание проекта

**Ситуация.** Цифровизация здравоохранения РБ: ЦИСЗ, FHIR BY, программа испытаний МИС. Частные центры первыми несут репутационные риски за качество КЗ в госреестре.

**Цель проекта.** Коммерциализация модуля Protocol как **обязательного предимпортного фильтра** КЗ в частных ОЗ и МИС.

**Задачи 2026-2028:** интеграция L0 в Айболит; регистрация ПО; 3-10 платящих клиник; финансовая устойчивость SaaS.

### 5. Описание продукции

**Продукт:** программный комплекс (SaaS / on-prem), не медизделие - **система поддержки принятия решений и контроля документации** (информационная система).

**Функции:**

- Поиск клинического протокола (RAG по корпусу Минздрава).  
- Проверка КЗ: 8 блоков, evidence_map, red flags.  
- `cisz_readiness` + `send_gate` (soft_gate по умолчанию).  
- API: `/api/consult-compliance-screen` (L0), `/api/consult-review/json` (L2).

**Технология:** Python/FastAPI, детерминированные правила + опционально LLM; развёртывание в контуре РБ.

**Лицензирование меддеятельности:** оказывается **медицинская помощь** (лицензия Кравиры); **Protocol** - вспомогательное ПО (информационная система), не медизделие; регистрация в реестре программ для ЭВМ (НЦИС).

### 6. Анализ рынка

**Сегмент:** частные амбулаторно-поликлинические организации РБ.

**Оценка объёма КЗ (допущение для БП):**

## 7. Слайды защиты (10 слайдов, финал)

1. **Проблема:** 478 КП, ЦИСЗ, 25k КЗ/мес только в Кравире.  
2. **Решение:** Protocol - два контура (клиника + ЦИСЗ).  
3. **Новизна:** детерминированный scoring + корпус Минздрава + FHIR BY.  
4. **Демо-скрин:** 3 карточки %, решение о подписи, чек-лист ЦИСЗ.  
5. **Архитектура:** L0 &lt;2 с в МИС.  
6. **Пилот Кравира:** KPI L0 &lt;2 с, 100% потока, gate &lt;70 (приложение В).  
7. **Рынок:** 25 000 = **1%** → **2,5 млн КЗ/мес** по РБ; TAM **29,7 млн BYN/год**.  
8. **Монетизация:** 0,69 BYN/КЗ (Кравira), масштаб до **8%** рынка к 2029.  
9. **Команда + ИС:** Кравира, регистрация ПО, Айболит.  
10. **Запрос:** сертификат 571 б.в., масштаб 5-10 ОЗ к 2028.
