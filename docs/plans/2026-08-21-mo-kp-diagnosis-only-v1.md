## 3. Проверка: подбор идёт от диагноза?

**Запрос - да. Рейтинг кандидатов - нет.**

Из 7605 визитов основа запроса:

- текст диагноза **7498** (98.6%), режим `text`
- только МКБ **64**, режим `icd_first`
- жалобы/анамнез **43**

Код МКБ берётся только из слотов диагноза (`mo_icd_resolve`), не из жалоб.
Но при живом тексте диагноза движок **выключает** `use_icd` и ищет по словам
по всему реестру (~6600 карт). Индекс кандидатов до #165 смотрел тело PDF;
после #165 омнибус режется по title/path, но обычные карты всё ещё могут
попасть из-за слов в содержании.

Поэтому top-1 после #165 всё ещё содержит заведомо чужие КП:

- первичная цилиарная дискинезия ×**90**
- трансплантация ГСК при иммунодефицитах ×**53**
- экстренная помощь детям ×**83**
- онко-алгоритмы 2018 №60 ×**96**
- гин. омнибус 2018 №17 ×**216** (не омнибус по правилу title, но dump МКБ)

J06 / M54 честно пустые - нозологического КП нет. Это правильно.

Итог: **не** «вычислить диагноз → взять протоколы этого диагноза по рейтингу».
Сейчас: «взять слова диагноза → найти похожую карту». Похожая ≠ та же нозология.

## 4. Канон v1 (жёстко)

```
1. Диагноз = слот «Клинический диагноз» / «Диагноз МИС» и/или код МКБ из этих слотов.
2. Нет ни текста, ни кода → пусто. Жалобы и анамнез КП не ищут.
3. Кандидаты = карты, у которых icd10_primary (паспорт, заголовок, путь)
   пересекается с кодом визита (точный или корень J06)
   ИЛИ (нет кода) название карты пересекается с формулировкой диагноза.
4. icd10_all из тела PDF в кандидаты не входит.
5. Кандидатов нет → пусто. Не подставлять «специальность» и не омнибус.
6. Рейтинг только внутри множества п.3: точный код > корень > совпадение названия.
7. clinical-хит только если точный/корневой код на primary ИЛИ сильное
   совпадение названия с формулировкой диагноза.
```

Цель hit после v1: **ниже 67% нормально**, если пропадут ПЦД / ГСК / экстренка
детям / онко-алгоритмы у неонко диагноза. Цель ложных top-1: **0** на этих
четырёх файлах в том же CSV.

## 7. Риски

- Hit упадёт на картах без `icd10_primary` (гин. 2026 №73 пустой ICD). Лечить
  паспорт, не ослаблять фильтр.
- Текстовый диагноз без кода («ОРВИ») идёт через название карты, не через
  тело PDF. Если названия нет - пусто.
- Оценки зоны плана изменятся после ночного score. Итог «Хорошо» может
  вырасти за счёт честного `na`, не за счёт ложного КП.
