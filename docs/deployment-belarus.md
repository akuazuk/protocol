# Развёртывание в контуре Республики Беларусь

Документ для обсуждения с ИТ-службой Минздрава и учреждений (не техническое ТЗ).

## Текущий пилот

- Веб-сервис (FastAPI + статический фронт).
- Корпус PDF синхронизируется с **minzdrav.gov.by**.
- Обработка естественного языка — внешний API по решению заказчика; ключ хранится на сервере.

## Целевая схема для масштабирования

1. **Сервер приложения** — ВМ или Kubernetes в дата-центре оператора / Минздрава.
2. **Корпус протоколов** — объектное хранилище или диск + ежедневная/еженедельная синхронизация с официальным каталогом.
3. **Модель NLP** — по решению заказчика:
   - разрешённый облачный API с договором и локализацией данных, или
   - on-premise языковая модель в контуре РБ.
4. **ПДн** — модуль проверки КЗ без выноса PDF в публичный интернет; аудит доступа.

## Минимальные требования (ориентир)

| Компонент | Ориентир |
|-----------|----------|
| RAM (полный RAG) | 2–4 GB |
| Диск (PDF + чанки) | 5–15 GB |
| HTTPS | Обязательно |
| Резервное копирование | index.csv, corpus_chunks_parts |

## Что не входит в пилот

- Прямая запись в медицинскую карту.
- Юридически обязательная экспертиза (МЭЭ).
