## 5. Критерии рубрики (канон)

| id | Параметр | Как оценивать | Регламент |
|----|----------|---------------|-----------|
| mo_complete | Проведение МО с оформлением | Полный объём данных по инструкции | №127 |
| datetime | Дата и время МО | Дата и время указаны | №127 |
| complaints | Жалобы | Указаны и детализированы | №127 |
| anamnesis | Анамнез | Объём, достаточный для диагноза | №127 |
| risk_factors | Факторы риска | Указаны в объёме для диагноза | №127 / КП |
| objective | Объективный осмотр | Полный объём; профильный статус по специальности | №127 |
| exam_data | Данные обследований | Указаны, если пациент принёс / есть в МО | №55 |
| diagnosis | Диагноз + МКБ | Из жалоб+анамнеза+осмотра(+обследований), с кодом МКБ | №55 |
| exam_plan | План обследования | По КП, с учётом уже выполненного | №55 / КП |
| treatment_plan | План лечения | По КП | №55 / КП |
| exam_correction | Коррекция обследований | С учётом динамики | №55 |
| treatment_correction | Коррекция лечения | С учётом динамики | №55 |
| follow_up | Кратность наблюдения | По КП / приказу №127 | №55 / №127 / КП |

Шкала: `0 | 0.5 | 1 | n/a`. `rubric_pct` = среднее по scored (без `n/a`) × 100.

## 6. Риски

- Heuristics depth (жалобы/анамнез) дадут шум без LLM/gold - держать shadow.
- Dynamics без prev visit нельзя считать дефектом (`n/a`, не 0).
- Не смешивать №127 checklist и №55 quality в один % без явных `n/a`.
- Не работать в грязном локальном `Protocol/` - только task worktree от `origin/main`.
