## 1. Контекст

Волна 1 закрыла механику: CI вкладок не гасят друг друга, конфликт в одной
строке `BUILD_VERSION` снимается автоматически, пересечение файлов считается
скриптом. Осталась причина, из-за которой пересечения вообще возникают:
**владение файлами нигде не объявлено до правки.**

Что видно в репозитории на 2026-09-05:

- 10 открытых PR, из них **7 зависли** больше 14 дней (26-27 дней у #77, #97,
  #113, #120);
- `docs/plans/README.md` держат **четыре** PR одновременно;
- 8 пар PR имеют жёсткое пересечение файлов;
- у 8 из 10 PR по имени ветки нельзя определить агента: сегмент `agent<N>`
  отсутствует, есть только `pc1`;
- ни `CODEOWNERS`, ни шаблона PR в репозитории не было, то есть требования
  `AGENTS.md` про «указать владельца, зону, зависимости» ничем не собирались.

Отдельно: `AGENTS.md` вёл за подробным workflow в
`multi-agent-single-repo-render-runbook-v2.md`, раздел 7 которого предписывал
деплой в Render. Render приостановлен и отдаёт `503`, Action удалён. Агент,
честно выполнивший канон, пошёл бы деплоить в мёртвый контур.

## 2. Что меняется в проде процесса

| Место | Было | Стало |
|--|--|--|
| Карта владения | нет | `.github/CODEOWNERS`, 6 уровней риска |
| Описание PR | свободный текст | шаблон с полями владельца, зоны, зависимостей |
| Имя ветки | конвенция только в тексте | блокирующая проверка `pr-hygiene` |
| Размер PR | не измерялся | предупреждение на 40 файлах / 1500 строках |
| «Кто держит файл» | `gh pr view` вручную | `pr_dashboard.py --files <path>` |
| Канон workflow | runbook v2 (Render) | `multi-agent-workflow-v3.md` (GCE) |
| Зависший PR | висит бесконечно | политика 14 дней, видна в дашборде |

Клиническая логика, оценка МО и флаги `*_PRIMARY` не затрагиваются: изменения
только в процессе и инструментах.

## 5. Риски

- **Блокирующая проверка гигиены останавливает работу.** Поэтому есть метка
  `hygiene-ack`, а пороги размера только предупреждают. Если проверка окажется
  шумной, снимать не её, а конкретное правило.
- **Плейсхолдеры шаблона берутся из самого шаблона.** Правка шаблона меняет
  список автоматически; тест `test_placeholders_come_from_the_template_itself`
  фиксирует, что список не продублирован в коде проверки.
- **`gh pr list` отдаёт максимум 100 файлов на PR.** Молча обрезанный список
  означал бы пропущенное пересечение, поэтому крупные PR дочитываются через
  API. На #192 это вскрыло девятую пару пересечений, невидимую до дочитывания.
- **`updatedAt` не годится для «завис»:** комментарий бота про пересечения
  обновляет PR, и августовский PR выглядел «сегодняшним». Возраст считается от
  `createdAt`.
- **CODEOWNERS с одним владельцем** не распределяет людей. Его смысл здесь -
  объявить уровень риска пути и дать branch protection зацепку для
  обязательного review.
