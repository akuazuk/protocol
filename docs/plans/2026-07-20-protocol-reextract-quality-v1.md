## 1. Контекст и проблема

В навигаторе протоколов Минздрава (proto-viewer, поиск «На приёме», карточка протокола)
было **много мусора**: юридическая обвязка («Национальный правовой Интернет-портал...»,
«Признать утратившим силу...», подписи министра, названия облисполкомов), заголовки глав,
обрывки предложений. Пункты попадали не в свои разделы.

Первопричины:
1. **Регекс-извлечение** (`auto_extracted`): 373 из 467 протоколов размечены регулярками по
   сырым чанкам PDF - отсюда обрывки ±40 символов, склейки списков, неверные разделы.
2. **Добивка разделов** сырыми чанками, когда LLM-сводка была разреженной.
3. **Неполный фильтр** boilerplate (не хватало белорусских юр-маркеров).

## 3. Что делается сейчас

LLM-переизвлечение 373 `auto_extracted` протоколов на Render Web Shell (Gemini; локально из
Беларуси Gemini geo-blocked, Anthropic без кредитов - поэтому запуск на Render).

- 4 параллельных воркера, `--publish --resume`, state и логи на `/var/data`.
- Резервное копирование извлечённых JSON в `/var/data` каждые 5 минут (rsync).
- **Прогресс на 19:30:** 84 / 373 (~23%); `llm_extractor` 80, `structured_fallback` 4;
  валидация: 55 valid, 29 needs_human_review; память 3.49 / 4 ГиБ; ETA ~3 ч.
- Пока идёт батч - **на main не деплоим** (редеплой Render убьёт воркеры).

## 6. Риски и меры

- **Редеплой во время батча убьёт воркеры** -> state и backup на `/var/data`, resume; на main
  не пушим до конца.
- **Эфемерная ФС Render** -> `REEXTRACT_STATE` и rsync-backup каждые 5 минут.
- **Потеря чанков не-переизвлечённых протоколов при ребилде RAG** -> `write_summary_rag_jsonl()`
  вызывается без списка, перечитывает все опубликованные сводки с диска.
- **Гео-блок Gemini / кредиты Anthropic** -> запуск из разрешённой локации (Render).
- **`needs_human_review` ~35%** -> это флаг на ревью, данные всё равно лучше регекса; ревью - отдельной задачей.
