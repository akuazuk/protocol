# Навигатор клинических протоколов Минздрава РБ

**Пилотная площадка:** медицинский центр «Кравира» 
**Источник нормативки:** [Клинические протоколы на сайте Минздрава](https://minzdrav.gov.by/ru/dlya-spetsialistov/standarty-obsledovaniya-i-lecheniya/)

## Проблема

- Около **450** действующих клинических протоколов - врач физически не держит все редакции в памяти.
- Разный уровень соблюдения стандартов → разное качество помощи, претензии пациентов, нагрузка на методслужбу.
- Консультативные заключения не всегда сверяются с протоколом **до** эскалации жалобы.

## Решение (три контура)

| Контур | Для кого | Что делает |
|--------|----------|------------|
| **Поиск протоколов** | Врач на приёме | Подбор КП по МКБ-10 / диагнозу, выдержки (обследования, лечение, алгоритмы), черновик КЗ |
| **Проверка КЗ (PDF)** | Заведующий, методслужба | Ориентировочная сверка заключения с протоколом (8 блоков), критерии, зоны риска (&lt; 70%) |
| **Проверь КЗ (B2C)** | Пациент | [`patient.html`](../patient.html) - самопроверка выписки простым языком, загрузка PDF/фото |

Ответы строятся **только по фрагментам официальных PDF** Минздрава. Не замена очного приёма, МЭЭ и юридической экспертизы.

## Пилот (предложение, 3 месяца)

| KPI | Как измерять |
|-----|----------------|
| Доля приёмов с открытым релевантным КП | Логи поиска / опрос врачей |
| Среднее время поиска протокола | Таймер в системе vs «вручную в PDF» |
| Доля КЗ с зоной риска по внутреннему аудиту | Модуль проверки КЗ |
| Обратная связь методслужбы | Протоколы разбора случаев |

**Площадки:** 2-3 учреждения + методический совет.

## Информационная безопасность

- Ключ обработки текста - **только на сервере**, не в браузере.
- КЗ с ПДн - **защищённый контур** учреждения; для демо - обезличенные PDF.
- Перспектива: развёртывание в **контуре РБ** (см. `docs/deployment-belarus.md`).
