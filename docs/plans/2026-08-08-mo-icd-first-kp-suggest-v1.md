# МО: КП строго по диагнозу (ICD-first) + точная сверка МКБ

Статус: **active**  
Дата: 2026-08-08  
Преемник для: части `2026-08-07-mo-dx-text-suggest-icd-directory-eval-v1` (КП без МКБ)
и `2026-08-08-mo-kp-suggest-dx-accuracy-v1` (когда в МО есть валидный код).

## Контекст

На кейсе психотерапевта с диагнозом/кодом **F41.2** UI показывал чужие КП
(вены, многоплодие, тромбофилии) с filler «Специальность · 15 баллов», и finding
«Формулировка диагноза слабо согласуется с рубрикой МКБ» при валидном коде в справочнике.

Корневые причины:

1. Suggest v4 искал КП **только по тексту** (`use_icd=False`, `icd10=[]`).
2. Код-only Dx (`F41.2`) очищался `strip_icd_tokens` → пустой query → baseline ~15.
3. «Психотерапевт» не маппился в `psikhiatriya-narkologiya`.
4. `B_icd_dir_text_mismatch` срабатывал при любом `text_rubric_fit < 0.25`, даже когда
   «текст» - только токен кода.

## Правило владельца

1. **КП ищем по диагнозу.** Если есть код МКБ и он есть в справочнике:
   - взять RU-название рубрики;
   - искать КП по коду (+ title), не по specialty-filler;
   - не показывать топ из 15-балльных specialty без ICD/text clinical hit.
2. Если код валиден в справочнике, а свободный текст пустой/только код →
   **согласованность с рубрикой OK** (mismatch только при осмысленном тексте,
   противоречащем title).
3. Если код валиден, но свободный текст **существенный и противоречит** title →
   mismatch остаётся; для КП в этом случае предпочитаем текст (код недоверен).

## Оценка обследований / лечения / рекомендаций (точность)

Цепочка:

```text
код/текст Dx → clinical KP hit → сверка плана с требованиями этого КП
```

| Шаг | Как определять точно |
|-----|----------------------|
| A. Диагноз | Код в справочнике + (title или substantive text fit). Code-only валидный код = ok. |
| B. КП | `match_kind=clinical` и (`icd_fit.weight ≥ 0.85` exact/root **или** lexical/bridge ≥ порога). Specialty/15 pts **не** КП для оценки. |
| C. Обследования | Coverage назначенного vs mandatory/recommended exams карточки КП (уже в alignment); без clinical KP → max 0.5 «план указан, КП не подтверждён», не 1.0. |
| D. Лечение / рекомендации | То же по treatment/recs блокам; полный 1.0 только при clinical KP + alignment блока ≥ 60. |
| E. Нет КП | Не штрафовать «не по протоколу» по чужой специальности; явно: «КП по диагнозу не найден». |
