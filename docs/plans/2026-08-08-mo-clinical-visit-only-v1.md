# МО: оценка только clinical_visit + №55 по пунктам (v1)

**Дата:** 2026-08-08  
**Статус:** active  
**Владелец решения:** только `clinical_visit`; стоматология вне оценки; процедурные визиты без балла; №55 - формула без na в знаменателе.

## Контекст

В контуре МО раньше в score входили `medical_exam` + `consultation`. Пользователь зафиксировал:

1. Оценивать только полноценный клинический приём (`clinical_visit`).
2. Стоматология - вне оценки.
3. Короткие процедурные записи (манипуляции) - метка, без балла.
4. Пост. МЗ №55: неприменимые пункты не в делителе; в карточке - номер пункта, описание, оценка, что не так.

## Метрики

| Метрика | Было | Цель |
|---------|------|------|
| Типы в score | medical_exam ∪ consultation | только clinical_visit |
| Процедуры ЛОР «на промывание» | consultation + score | procedure_session, без score |
| Стоматология | non_clinical (часто) | non_clinical, без score |
| №55 na в знаменателе | нет | нет (сохранить) |
| Служебный red-flag в формуле | да (fail) | нет (вне формулы) |

## Шаги

- [x] Taxonomy: `clinical_visit`, `procedure_session`; SCORED = {clinical_visit}
- [x] SQL/KPI/publish/recompute на clinical_visit
- [x] №55: point_no, whats_wrong_ru, score_eligible=false для служебного пункта
- [x] UI: колонки Пункт / Описание / Оценка / Что не так
- [ ] После merge: GCE deploy + `recompute_mo_days` за актуальные дни (переклассификация витрины)
- [ ] Smoke: день → только «Клинический приём» с баллом; процедура без балла; №55 таблица

## Риски

- До recompute в витрине останутся старые `consultation` с баллами - KPI временно занизят eligible.
- Эвристика процедур может редкий полноценный приём с манипуляцией пометить как procedure_session - смотреть `document_kind_reason`.
