# Вернуть разбор МО как оценку случая (v1)

Статус: **active**  
Дата: 2026-09-27  
Связано: `2026-09-27-mo-client-passport-score-ui-v2.md` (шаги P4-P6),
шкала `2026-08-20-mo-grade-ladder-v1.md`.

Цель: методист снова видит, почему МО плохое, без мастера из пяти шагов.

## Контекст

После P4-P6 столбец `#case-review-pane` заменялся мастером. На ширине
&lt; 1100 px вкладка по умолчанию была «Документ» - оценка не видна, пока
её не откроют. Решение методиста пряталось до шага 5.

Шкалу и сентябрь не трогаем. Это только UI разбора.

## Что должно быть на экране, чтобы найти плохое МО

1. Итог (`overall_grade` + `reason_ru`).
2. Три зоны с причиной.
3. «Почему так» - до 4 строк склада.
4. «Что не так» - findings.
5. Доказательства (№55 / КП / история / лаб).
6. Решение методиста сразу, не на пятом шаге.

Паспорт - одна строка над оценкой. Не хозяин разбора.

## Волны

### R0. Умолчание - старый столбец проверки

- Мастер только при `?steps=1`.
- Вкладка по умолчанию - «Проверка».
- `#case-review-pane` снова рисует зоны, почему, findings, evidence.
- Паспорт одной строкой над «Оценка случая».

Результат: открыть слабо / важно - сразу видно, почему плохо.

### R1. Язык и решение

- Переименовать «Линза» / «Доказательство» в мастере (`?steps=1`).
- Решение видно и при включённом мастере, не только на шаге 5.

### R2. Сжать только если после R0/R1 всё ещё нельзя найти плохое МО

Не делать старый G-скролл и K-ленту 180 дней.
