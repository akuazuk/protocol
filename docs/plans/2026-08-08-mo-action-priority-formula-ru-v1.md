# МО: приоритет очереди по формуле + русские уровни вместо P0-P3

Статус: **active**  
Дата: 2026-08-08

## Контекст

В очереди «Вчера» почти все строки - `P0: Критический дефект по №55 · оценка 40%`,
хотя у врача по LLM-судье П/Д/Р и по формуле №55 балл выше. Причины:

1. В warehouse остались stale `D_reg55_p0` (старый критерий `manual_review` как P0).
2. В актуальном `mz_2021_55.json` **нет** P0-критериев - finding ложный.
3. Любой P0 hard-cap'ает `overall_pct` до 40% - UI показывает «оценку 40%».
4. Колонка «Приоритет» рисует сырой код `P0`/`P1`, не понятный методисту.

## Решение владельца

1. Stale `D_reg55_p0` при отсутствии P0 в каталоге → demote до P1, заголовок как gap по №55.
2. Приоритет в очереди - **по формуле** (пересчитанный overall из осей после demote,
   иначе `overall_pct` / `reg55_pct`): полосы Критично / Важно / Проверить / Низкий.
3. Везде вместо `P0`…`P3` - короткие русские слова и **разные цвета**.

## Метрики

| | Было | Цель |
|--|------|------|
| Очередь P0 по №55 без реальных P0-критериев | доминирует | 0 (demote) |
| Подпись приоритета | `P0` | `Критично` / `Важно` / … |
| Цвета уровней | critical vs review | 4 тона |
