## 2. Переосмысление (что было неверно в v1)

Кейс: визит `3600047`, мигрень, план с эсциталопрамом + суматриптаном + **мелоксикамом**.

| Гипотеза v1 | Факт |
|--|--|
| DDI тянут ЛС из анамнеза («Нимессил») | Нет: `_axis_safety` уже берёт только `treatment_recommendations` |
| Нужны ручки «Major DDI → Важно» в Настройках | Рано: без gold/калибровки это ломает доверие; методисту нужнее **честные findings** |
| Колонка приоритета во всех таблицах | Слабый ROI: рабочая поверхность - Очередь / Обзор; дублировать P-колонку = шум |
| Deep-rescore из UI как следующий шаг после ярлыков | Важно, но **после** фикса нормализации ЛС, иначе пересчитаем ту же ошибку |

**Корневой баг кейса:** `мелоксикам` нормализуется в INN **`diclofenac`** (override/seed, confidence 0.98). Отсюда ложный Moderate DDI `diclofenac + escitalopram`. Реальный Major `escitalopram + sumatriptan` при этом остаётся правильным поводом для **Важно**.

## 3. Цель v2

Методист на кейсе вроде 3600047 видит:

1. одно **Важно** по суматриптан + эсциталопрам (с цитатой из плана);
2. при необходимости **Умеренно** по мелоксикам + эсциталопрам (НПВП+SSRI), **без** слова diclofenac;
3. пустые блоки обследования/наблюдения - **Оформление**, не раздувают «критичность»;
4. в Настройках понимает: потолки = «насколько сильно режем балл», а не «что считать критичным»;
5. на дашборде видит **статистику по четырём уровням** (кольца) и по клику попадает в таблицу
   случаев, отфильтрованную по выбранному уровню.

## 4. Канон приоритетов (без изменений)

| Код | UI | Когда |
|--|--|--|

### D. Дашборд: кольца по Критично / Важно / Умеренно / Оформление + drill-down

Экран: **Обзор** (и при необходимости блок на **Безопасность** вместо тонких stacked bars).

**Статистика**

- Счётчики за текущий `#period` / фильтры context-bar: сколько случаев с worst-severity
  Критично / Важно / Умеренно / Оформление (и отдельно «без замечаний», если нужно).
- Источник: уже есть `severity_totals` / safety dimension / warehouse `p0..p3`;
  при необходимости один endpoint `severity-dashboard` с долями и `n`.

**Диаграммы**

- ECharts **doughnut** (кольца), не pie на всю площадь.
- Один ряд: либо **одно кольцо** с 4 сегментами уровней, либо **4 кольца** (уровень vs остальное) -
  предпочтительно **одно кольцо + легенры KPI**, чтобы не дублировать «Сегодня»-зоны.
- Клик по сегменту / легенде → переход в таблицу разбора:
  - цель: **Очередь** (для Критично/Важно) или **Все случаи** с фильтром `min_severity`
    / `severity=P0|P1|P2|P3` (wire) и подписью фильтра на русском;
  - URL/state сохраняет фильтр (можно шарить ссылку);
  - таблица показывает те же колонки, что очередь/день, с причиной и приоритетом.

**Визуальный канон колец (здесь и везде в МО)**

Сейчас у колец зон примерно `radius: ["56%", "78%"]` - кольцо тонковато и бледновато.
Канон для всех doughnut МО (приоритеты, зоны «Сегодня», №55, будущие кольца):

| | Было (ориентир) | Цель |
|--|--|--|
| Толщина кольца | ~20-22 п.п. (`56-78%`) | **толще**: внешний ≥80%, внутренний ≤48% (полоса ~32+ п.п.) |
| Контраст сегментов | soft mix | насыщенные `--bad` / `--warn` / check / formal; фон hole светлый |
| Обводка | слабая | `borderWidth` 2-3, цвет surface, чтобы сегменты не сливались |
| Центр | мелкий % | крупный **N** или доля выбранного уровня; подпись русская |
| Легенда | сырые коды | только Критично / Важно / Умеренно / Оформление |
| Hover | default | подсветка сегмента + «открыть N случаев» |

Общий helper в `mo-charts.js` (например `MO.moDonut`) - один стиль на Обзор, Сегодня, Безопасность.

## 7. Риски

- Починка override может сдвинуть другие NSAID-матчи - нужен короткий список регрессий (мелоксикам, диклофенак, нимесулид, ибупрофен).
- После A без re-score UI останется со старыми findings в warehouse.
- Слово «Критично» в двух смыслах останется; справка обязательна.
- Drill-down по worst-severity ≠ «все findings этого уровня» - в подписи фильтра писать
  «худший уровень замечания», чтобы не ждали полный список P3-замечаний внутри Критично-кейсов.
- Смена толщины колец зон затронет `mo-today-rings` - делать одним helper, не копипастой.
