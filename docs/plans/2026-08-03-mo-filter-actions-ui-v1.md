## Контекст

Верхняя панель МО перегружена постоянно видимыми полями. Множественные фильтры
применяются сразу после установки флажка без явного подтверждения, поэтому интерфейс
выглядит безучастным. Значение поиска из URL, например `q=Pavel`, визуально похоже
на системное значение по умолчанию.

## Что изменено в проде

До этой задачи в проде действует прежняя панель: поиск по событию `change`,
моментальное применение флажков и плоский ряд действий. Новая версия ещё не
развёрнута.

## Риски

- Большое меню фильтров может не помещаться на узком экране. На мобильных оно
  переводится в фиксированную прокручиваемую панель.
- Закрытие фильтра без применения должно отменять черновой выбор, чтобы состояние
  UI не расходилось с фактически загруженными данными.
- Параметр `q` нельзя молча удалять из ссылки: он может быть частью сохранённого
  представления. Вместо этого активный поиск показывается чипом с явной очисткой.
