## 0. Требования владельца (2026-09-26), которые меняют направление

1. **Ничего не скрывать.** Никаких «Ещё» в меню и свёрнутых по умолчанию блоков в разборе.
   Каждый экран и каждый блок виден сразу; сворачивание - только по желанию пользователя.
2. **Дашбордов много, и они стильные.** Каждый раздел (Обзор, Врачи, Лекарства, Анализы,
   Поиск МИС, Очередь, Отчёты, Протоколы МЗ, Инструкции) получает свой набор диаграмм.
   Сейчас 3 из 9 экранов вообще без графиков (Лекарства, Анализы, Очередь).
3. **Шрифты.** Сейчас `"Avenir Next"` - системный шрифт macOS; на Windows это Segoe UI,
   на Linux - что попало. Нужен свой webfont с кириллицей и табличными цифрами.
4. **Всё должно работать и всё грузиться.** Замеренные дыры: холодный `/cases` 12,1 с,
   сверка КП МЗ стоит с 2026-08-26, Rceth с 2026-08-18, «догрузка случая» выполняется
   только ночью в 02:00, а не по кнопке.
5. **Данные по МО и анализам минимум с начала года** с возможностью догружать конкретный
   случай. Сейчас клинических МО с оценкой - только с 2026-07 (июль 2699, август 11348,
   сентябрь 10527). Январь-июнь: 77 000 документов в складе как `consultation` /
   `diagnostic` без зон и без текста диагноза. Лаборатория есть с 2025-12 (484 964 строк).
6. **Умный поиск.** Не «слово в слово»: болезнь → коды МКБ + формулировки + синонимы +
   опечатки + похожие.

Этот план - полный: он включает всё, что осталось в силе из v1 (шкала, состав замечаний,
контракт фильтров, лента пациента, инструменты измерения) и всё, что найдено 2026-09-26.
Сводный реестр «проблема → волна» - раздел 11; ничего из найденного без волны не остаётся.

## 3. Целевой продукт

Кабинет, где методист **за один экран без кликов** видит картину периода в диаграммах,
за один клик - список случаев, за один клик - полный разбор, где **всё развёрнуто**.
Любой раздел открывается из левого меню напрямую. Любой поиск понимает язык врача.
Данные - с 1 января, а недостающий случай или история пациента догружаются по кнопке
за секунды, не ночью.

## 4. Дизайн-система (что именно меняется)

### 4.1 Шрифты

### 4.2 Сетка и плотность

- Шапка ≤ 120 px на ≥ 1280 (две строки: периоды + даты + поиск; чипы оценки + фильтры),

Единый стиль: сплошные заливки без штриховок; палитра оценки строго из `mo-tokens.css`
