# Результат внедрения ежедневной аналитики МО

**Дата:** 2026-07-28

## Что изменилось

- Ежедневный pipeline самостоятельно выключает VanyaVPN перед SQL, получает данные за
  вчера, проверяет качество, классифицирует документы, оценивает допустимые случаи,
  формирует отчёты и восстанавливает исходное состояние VPN.
- Установлены задания macOS: основной запуск 07:00, повтор 10:00 и hourly catch-up.
- История 2026 года перенесена в локальную SQLite-витрину без повторной нагрузки на БД.
- Добавлен CRM/BI-дашборд МО с множественным выбором месяцев, филиалов, специальностей,
  врачей, типов документов и статусов.
- Реализованы очередь разбора, решения методиста, аудит событий, saved views, приватные
  выгрузки, detail drawer и прозрачное описание методики оценки.
- Пользовательская терминология разделена: МО для массового анализа из БД, КЗ в
  пациентском сценарии, «Анализ документа» для одиночной загрузки КЗ или МО.
