# Model Card: Онконастороженность (Protocol)

Версия базы знаний: 2026-06-30. Код: `clinical_knowledge/onco_risk.py`. Данные: `data/onco_risk/`.
Сборка сервера на момент релиза: см. `BUILD_VERSION` в `/api/version`.

## Назначение

Советующий (decision-support) триаж онконастороженности по тексту заключения, возрасту, полу и анализам. Помогает врачу решить, нужен ли путь дообследования; пациенту - сформулировать нейтральные вопросы врачу.

**Это НЕ диагноз, НЕ скрининговая программа и НЕ влияет на `send_gate`.** Итоговое решение - за врачом.

## Входы и выходы

- **Входы:** свободный текст (жалобы/анамнез), `age`, `sex`, текст анализов, флаги (курение, семейный анамнез, длительность), `adult_or_child`.
- **Выходы (B2B):** контекст, триаж против порога 3%, риск по локализациям с 95% интервалом и водопадом вкладов, общий онкориск, индикатор полноты данных, источники, method note.
- **Выходы (B2C):** только нейтральные вопросы врачу - без чисел и без слов «рак/онколог/опухоль/метастаз и т.п.».

## Метод

1. Извлечение признаков по ключевым стемам с фильтром страт (пол/возраст).
2. Классификация контекста: symptomatic / surveillance / screening / hereditary / pediatric.
3. Гейт полноты данных: при низкой полноте - только качественный сигнал + дозаполнение (L-Intake).
4. Байес на отношениях правдоподобия: pre-test (priors РБ) -> post-test по LR; зависимые признаки с поправкой (первый признак полностью, последующие с коэффициентом 0.5); кап вероятности 0.9.
5. Доверительный интервал через Beta, концентрация масштабируется полнотой данных.
6. Триаж: порог направления 3% (NICE NG12), для детей ниже.

## Источники данных

- **LR / PPV:** CAPER (Hamilton 2009, DOI 10.1038/sj.bjc.6605396), NICE NG12.
- **Priors (Беларусь):** IARC GLOBOCAN 2022, РНПЦ ОМР им. Н.Н. Александрова; фоновые риски симптоматического звена из CAPER.
- Полный список и оговорки: `data/onco_risk/sources.md`.

## Допущения и ограничения

- **Независимость признаков** соблюдается лишь приближённо - отсюда поправка-шринк и широкий CI; это не замена многомерной модели (QCancer - цель будущего).
- **Калибровка LR - UK (CAPER/NICE)**; priors - РБ. Перенос LR между популяциями допустим, PPV - нет.
- **Возрастные priors частично approx** (crude годовая заболеваемость); требуется рекалибровка по IARC CI5 / РНПЦ (Фаза 4).
- **Скрининговые возрасты - ориентир**, подлежат подтверждению по протоколам МЗ РБ.
- **Редкие локализации и детская онкология** покрыты ограниченно; пороги для детей заданы консервативно без точных PPV NICE.
- Извлечение признаков - стем-матчинг по тексту: возможны пропуски при нетипичных формулировках.

## Контуры и запреты

- **B2B:** числа, CI, водопад, источники - для врача.
- **B2C:** запрещены проценты и «страшные» слова (`forbidden_words` в `b2c_question_templates.yaml`), проверяется тестами; тон поддерживающий, с safety-netting.
- **Не gate:** оценка не участвует в `send_gate` и не блокирует отправку.
- **Приватность:** рантайм - локальный lookup + арифметика, без внешних вызовов и без выгрузки ПДн.

## Интеграция

- `POST /api/onco-risk` - советующий ответ (audience b2b|b2c|both).
- `/onco-risk.html` - демонстрационная панель (B2B) и карточка вопросов (B2C).
- Patient-флоу: B2C-блок «Что полезно уточнить у врача» за флагом `PATIENT_ONCO_QUESTIONS_ENABLED` (по умолчанию выкл).

## Валидация (план)

- Метрики: чувствительность/специфичность триажа на размеченных кейсах, калибровка (reliability curve), доля «refer» и её обоснованность.
- Рекалибровка priors по CI5/РНПЦ; пересмотр LR при наличии локальных данных.
- Регресс-тесты: формулы, пороги, полнота, безопасность B2C (`tests/test_onco_risk.py`, `tests/test_api_onco_risk.py`).

## Контакты и ответственность

Инструмент советующий; ответственность за клиническое решение несёт врач. Изменения базы знаний фиксируются в `data/onco_risk/sources.md` и в истории git.
