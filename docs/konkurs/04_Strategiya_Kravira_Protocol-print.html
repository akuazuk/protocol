Проект и организация

Protocol - предимпортная экспертиза консультативных заключений и сервис проверки КЗ для пациентов

Общество с дополнительной ответственностью «Медицинский центр «Кравира»»

Уровень коммерциализации

отмечены: определены способы монетизации (B2B микроплатёж + B2C для физлиц), ценовая политика, каналы продаж (МИС, клиники, веб-витрина); определён потенциальный заказчик - МЦ «Кравира»; предварительный вывод на рынок - письма заинтересованности оформляются до 01.08.2026.

Опытный образец, B2B-пилот в Кравире, beta B2C (2027).

Способы коммерциализации

реализация услуг (B2B проверка КЗ, B2C самопроверка для физлиц); предоставление права использования (лицензия API для МИС); заинтересованность (письма клиник и интегратора МИС).

План на ближайший год

1) Завершить пилот L0 в Кравире и метрики B2B. 2) Запустить beta B2C: загрузка КЗ физлицом, оплата 4,99/9,99 BYN, дисклеймер и политика ПДн. 3) Интегрировать API в МИС «Айболит». 4) QR-кампания «Проверьте своё заключение» в Кравире. 5) Подключить 2 внешние клиники B2B.

Стратегия на 5 лет

2027: Кравира B2B + B2C beta. 2028: 5-10 ОЗ B2B, 30-50k B2C проверок/год. 2029: white-label МИС, 5% рынка B2B. 2030: госсектор/сети. 2031: регион ЕАЭС, адаптация корпуса КП.
