# Протоколы МЗ: даты, периоды и диаграммы (v1)

Дата: 2026-08-14  
Статус: **active**  
Связанные: `2026-08-13-minzdrav-kp-daily-sync-v2.md` (пайплайн сверки остаётся каноном).

---

## Контекст

Вкладка МО «Протоколы МЗ» после PR #142 показывала только снимок последней ночи: сайт / корпус / added+updated. Методисту нужны **две шкалы дат** и сводки:

1. **Дата постановления МЗ** - из имени/заголовка (`ДД.ММ.ГГГГ №N`).
2. **Дата сверки у нас** - из `kp_sync_YYYY-MM-DD.json`.

Пайплайн ночи не меняем. Только payload `/api/methodist/mo/kp-sync` и UI.

---

## Что в проде после этого PR

- KPI: сайт, корпус, ночь, сверка; плюс посты 7/30/90 / с начала года / 2026 и «к нам за 30 дн».
- Таблица периодов: посты МЗ vs новые/обновлённые у нас vs число ночей (7/30/90/YTD).
- Диаграммы: поступления по ночам (stack), посты по месяцам, посты по годам, рубрики (donut).
- Таблицы: журнал ночей, свежие посты МЗ, last-night changed, superseded.
- В строках: рубрика, файл, дата поста, дата сверки, статус.

## Метрики

| | Было | Стало | Цель |
|--|--|--|--|
| Оси дат на вкладке | только ночь сверки | пост МЗ + сверка | обе оси в KPI, таблице и списках |
| Сводка периодов | нет | 7 / 30 / 90 / YTD + 2026 | цифры без выгрузки JSON |
| Диаграммы | нет | 4 (ночи / месяц / год / рубрика) | видно волну постов 2026 и ночной catch-up |
| Журнал ночей | нет | таблица history | дата + added/updated/superseded |
