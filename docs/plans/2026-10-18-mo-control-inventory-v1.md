Источник интерфейса: `frontend/web/methodist/mis-kz-quality.html` и `frontend/web/shared/mo-app.js` на `6f8da0f8`.
Склад: GCE `mo_analytics.sqlite`. Верх даты визита на этой сверке: `2026-10-17`.

Документ - приёмочный список. Волна не закрыта, пока строка списка не имеет одного из статусов: `верно`, `подпись врёт`, `мёртвый контрол`, `не нажимать`. Новые экраны сюда добавляются до кода, не после.

## Два окна, которые нельзя путать

Кнопки периода по умолчанию стоят на «Месяц». «Месяц» - с 1-го числа текущего месяца по вчера (Минск), не до конца календарного месяца. 18 октября 2026 это `2026-10-01` - `2026-10-17`.

«С начала года» на ту же сверку: `2026-01-01` - `2026-10-17`. Таблица года ниже обрезана по `2026-10-16`, потому что предыдущая сверка так фиксировала верх. День `2026-10-17` посчитан отдельно и входит в месяц.

Клинические визиты, оценка записи:

| Оценка | 1-17 октября 2026 | 1 января - 16 октября 2026 |
|---|---:|---:|
| Хорошо | 1993 | 4040 |
| С замечанием | 2543 | 34048 |
| Слабо | 2362 | 17909 |
| Важно | 95 | 824 |
| Критично | 0 | 0 |
| Нет оценки | 0 | 0 |
| Всего | 6993 | 56821 |

Вчера относительно 18 октября, то есть `2026-10-17`: 306 клинических, из них важно 5, критично 0, хорошо 73, с замечанием 105, слабо 123.

Чип «Нет оценки» на «Найти МО» для клинических визитов пустой в обоих окнах. Пустые оценки есть у других видов документов (консультация 51403, диагностика 11416, профосмотр 9319 за год до 16 октября), и они в этот список не входят. Пустое состояние чипа: «Среди клинических приёмов записей без оценки нет. Консультации и профосмотры в эту таблицу не попадают.»

| Поиск, Найти, Очистить | `q`, либо `icd`, либо `visit_id` / `patient_id` | Полное ФИО врача находится. ФИО пациента не ищется. Число из подсказки врача равно числу после Enter | Поиск ФИО починен. Пустое состояние про пациента ещё не написано |
| Подсказка поиска | Кладёт строку в то же поле и отправляет `q` | Не отдельный фильтр | Верно после правки регистра |

Ноль не прячет кнопку | Сейчас на кнопке только слово, число видно после открытия таблицы. Волна B пишет число на чип. Две копии одного состояния: полоса и селект «Оценка МО». Селект подписать «то же, что чипы сверху» |
| Сравнение: предыдущий период / тот же день недели / без сравнения | `compare_period` | Меняет дельту плиток и колец, не состав списка | Подпись дельты «к прошлому периоду» при режиме «тот же день недели» врёт. Волна B: дельта говорит, с чем сравнивают |
| Месяцы | `month`, и при непустом выборе `query()` не ставит `date_from` | Один месяц из списка заменяет период шапки | Легко получить чип «Месяц» в шапке и другой месяц в фильтре. Волна B: выбор месяца в панели переключает пресет периода и показывает даты в шапке |
| Филиалы | `filials`, значения через `\|`, не через запятую | Адрес с запятой не режется | Уже так в коде. Контракт: филиал «ул. Захарова, 50Д» за год до 16 октября = 25508 |

Пустой результат по битой ссылке надо объяснять чипом «статус не из списка разбора» |

| Представления: план по КП | Зона 2b bad, КП подобран, attention_only | За тот же год bad+matched = 8066, все уже с вниманием | Подпись честная, если шапка показывает «план плохо, протокол подобран», а не оценку «Слабо» |
| Представления: оформление слабо | Зона 1 bad, без attention_only | 12144 за тот же год | Слово «слабо» здесь про зону, не про оценку «Слабо». Волна B переименовывает в «Оформление: плохо» |
| Первый контакт + слабый план | Зона 2b bad и `history_tier=first_contact`, attention выключен | 5938 за тот же год | «Слабый» в кнопке, в запросе полоса bad. Переименовать в «Первый контакт, план плохо» |

## Обзор

Страница `yesterday`. Скрытая секция `overview` («Период») в меню не попадает: `switchPage` переписывает `overview` в `yesterday`. Плитки `month-kpis`, кольцо приоритета, тренд месяца, №55 месяца, чип МКБ месяца и клинические разрывы на скрытой секции. `loadOverview` всё ещё может вызваться из `ensureSummary` и рисовать в скрытый DOM. Волна B не открывает эту страницу заново. В приёмку глаза она не входит. Если запрос нужен только скрытому DOM, его не показывать как часть Обзора.

| Контрол или показатель | Верный смысл | Приёмка |
|---|---|---|
| Плитка «Оценено» | Число допущенных клинических в окне шапки | На месяце 6993, не 56821 |
| Плитка «Нужен разбор» | Сумма очереди «критично» и «важно», не чип оценки «Важно» | Подпись уже говорит «критично + важно». Клик не подменяет чип «Важно» |
| Плитка «Свежесть» | `data_through` склада | На сверке не раньше 2026-10-17. Если плитка старше верха склада, это дефект даты, не «пустой день» |
| Скачать отчёт | POST экспорт текущего среза | В проходе приёмки не нажимать. Кнопка вторичная на вид, сейчас она первая и выглядит главной. Волна B меняет местами с «Открыть очередь» |
| Открыть очередь | Страница очереди, полоса по умолчанию «критично и важно» | Не включает чип оценки |
| Поделиться ссылкой на срез | Копия адреса | Как «Скопировать ссылку» |
| Лента оценок | Доли по дням. Клик: этот день и эта оценка в «Найти МО» | День - дата Минска. Клик по 17 октября и «Важно» даёт 5 |
| Три зоны | Доля «хорошо» и дельта к сравнению | Дельта больше 10 п.п. только у оформления уже поясняется скачком методики. Клик сегмента открывает зону и полосу, не оценку записи |
| Тренд зон | Средние проценты трёх зон по дням | Клик, если он есть, не меняет оценку записи молча |

## Найти МО

Колонки: визит, пациент, дата, врач и специальность, филиал, диагноз, МКБ, история, КП, оценка, оформление, диагноз-зона, план, причина, №55, открыть.

| Контрол | Верный смысл |
|---|---|
| Нужен разбор | `queue_only`, не чип «Важно» |
| Колонки | Прячет необязательные. Оценка и причина не прячутся без предупреждения |
| Сортировка: дата, балл, балл №55, приоритет | Приоритет не равен оценке. Подпись селекта: «приоритет очереди, не оценка записи» |
| Порядок | Новые сверху / старые сверху. На сортировке по баллу подпись «сначала новые» врёт. Волна B: «по убыванию» / «по возрастанию» |
| Экспорт всей выборки | Файл среза. В приёмке не нажимать |
| Сводка: оценки, специальности, недели | Клик сужает тот же запрос |
| Строка и «Открыть» | Разбор этого визита |
| Пейджер | `page` списка, не смена периода |

Пациент в колонке - идентификатор, не ФИО. В отчёт сверки идентификатор не копировать.

## Лекарства

Верхние плитки (взаимодействия, дубли) входят в оценку записи. Нижние (доза, не по протоколу) - сигнал и в оценку не входят. Общий бейдж «черновик, не в общей оценке» с шапки снимается в волне B.

Клик по типу, препарату, специальности, неделе, паре открывает код или пару в «Найти МО». Пара показывается от 10 случаев. Пусто при ненулевых взаимодействиях: «Нет пары, которая встретилась хотя бы 10 раз.»

## Анализы

Бейдж черновика остаётся: лабораторный код не ставит полосу безопасности. Подпись отличает экран от вкладки анализов в Поиске МИС.

Клики: окно лаборатории, неучтённый тест, специальность, неделя. Все ведут в клинические визиты с кодом, не в каталог МИС.

## Пациент

Поле «визит или ключ паспорта», кнопка «Открыть паспорт». Пустой ввод не ходит в сеть. Неизвестный визит: «В складе такого визита нет.» ФИО нет в поле и в ответе.

| Журнал доступа | Администратор. Методист видит «только администратор» |
| Качество данных | Свежесть и полнота. Пропуски не называются плохими МО |

## Протоколы МЗ

Плитки свежести, сводка по дате постановления и по дате ночной сверки, графики поступлений, постов по месяцам и годам, рубрики, свежие посты, изменённые у нас, заменённые на сайте. Клик по протоколу не фильтрует «Найти МО», если только карточка явно не обещает случаи. Сверка старше 7 дней видна в шапке датой, не только цветом.

## Инструкции ЛС

Статус синхронизации, плитки, журнал прогонов. Ноль ошибок прогона не прячет «нужно человеку». Замечания по назначениям здесь не список МО: текст отсылает в разбор и на «Лекарства».

## Вход

Логин и пароль, либо токен. Ошибка входа в `#auth-error`, без текста токена. Успех открывает Обзор на периоде «Месяц».

## Что второй проход меняет в остальных документах

- Годовые 824 и 56821 не являются экраном по умолчанию. Приёмка волны A называется и для месяца (важно 95, критично 0), и для года.
- Страница «Период» не цель вёрстки.
- Команды ⌘K для трёх периодов - дефект дат, чинится в волне B вместе с подписями.
- Чип «Нет оценки» - мёртвый на клинических приёмах, ему нужен честный ноль, а не скрытие кнопки: иначе человек решит, что фильтр сломан.
- Пороги в справке не переименовывают чипы. Их не крутить в проверке.

Живые кнопки, которые программа сознательно не нажимает ни в одной волне, кроме отдельного окна пересчёта F: экспорт, печать, PDF случая, «проанализировать», сохранить жёсткость, «на след. загрузку», пересчитать, deep-пересчёт, флаг обучения.
