## 2. Аудит прода 2026-09-21 (без PHI)

Источник: склад GCE `/var/data/medical_exams/warehouse/mo_analytics.sqlite`, UI `protocol.kravira.by`, контейнер `protocol-web`.

### 2.1 Протоколы не определяются - это склад, не только экран

Сентябрь 2026, `document_kind=clinical_visit`: **8220 / 8220** с `zone2b_kp_status=unmatched`.

Весь склад:

| Поле | Факт |
|--|--|
| `zone2b_kp_status = matched` | **0** строк за всё время |
| `protocol_id` непустой | **0** строк |
| `protocol_applicability_status` сентябрь | `not_evaluated` / пусто, не `applicable` |
| `zone2b_band` сентябрь clinical | все `na` (следствие R1: без КП план не штрафуем) |

Следствие на Обзоре: плитка «План плохо **0%**». Это не «все планы хорошие». Это «план ни разу не сравнивали с КП».

Почему так в коде:

1. Ночной скоринг зон берёт `protocol_suggest` из контекста. Если его нет или нет `clinical_kp_hit`, `_kp_matched` → unmatched, `protocol_id` не пишется.
2. Живой suggest при открытии случая - **другой** запрос (`/protocol-suggest`). Он может показать имя КП на экране, пока склад остаётся unmatched. Методист видит то одно, то другое.
3. `ILEX_PASSPORTS` в контейнере **не задан**. Overlay паспортов из плана 2026-09-18 на проде не включён.
4. R1 специально запретил рисовать fail плана без КП. Без матчера это превратилось в вечный `na` и нулевой «План плохо».

Канон не меняем: чужой КП хуже пустого. Цель - **настоящий** hit по Dx/МКБ/Ilex, а не ослабить порог trust, чтобы закрыть 0%.

### 2.2 Графики Обзора - те же

На проде Обзор: 4 кольца 235×162 (оформление / диагноз / план / №55) + один линейный тренд 1084×282. Легенда колец **не** шкала Хорошо/Слабо/Важно (хвост W7 п.3). Визуал Chart.js/ECharts на старых токенах. Новых типов нет - оба предыдущих плана это **запрещали**.

«План» на кольце и тренде читается как качество плана, хотя витрина плана пустая из-за unmatched.

### 2.3 Решение методиста

R7 поставил `<details ... open>`. Запрос владельца: спойлер **свёрнут** (видна только строка «Решение методиста», форма по клику). На 1440 док всё равно прижат вниз колонки flex-ом.

## 3. Целевой продукт

Методист за 30-60 с:

1. На Обзоре видит **понятные** кольца одной легенды оценки, тренд, куда идти. «План» имеет смысл только если КП подобран у доли случаев.
2. В списке и в разборе **видно имя КП**, если hit настоящий; иначе одна фраза «протокол не подобран», без второго смысла.
3. Склад, ночной скоринг и живой suggest **согласованы**: `protocol_id` / `zone2b_kp_status` те же, что на экране после пересчёта.
4. Решение методиста свёрнуто, пока человек сам не откроет.

Не цель: Pareto/heatmap/treemap (канон v2 выкинул). Не цель: штрафовать план без КП.
