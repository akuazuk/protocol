МЦ «Кравира» · перед ЭЦП и отправкой в ЦИСЗ

Чек-лист перед подписью консультативного заключения

Пациент: __________________
Дата приёма: __.__.____
Врач: __________________

МИС формирует FHIR-пакет (Bundle) и перед подписью показывает оценку Protocol: send_gate и gate_score = min(клиника по КП, готовность к ЦИСЗ). Если балл ниже порога учреждения (обычно 70%) - доработайте форму, затем подписывайте.

Сохранить в МИС→ Protocol L0→ gate OK?→ ЕСИФЮЛ→ ЦИСЗ

Критично - не подписывать

  • Пациент - верный человек (ИНП / ФИО / ДР)
  • МКБ-10 соответствует формулировке диагноза
  • Не отправлять «?» / предварительный как заключительный
  • Подписант = вы (author в пакете)
  • Организация = ваше ОЗ (custodian)

Важно - частые претензии

  • Жалобы и осмотр не пустые / не шаблон
  • Назначения: препарат, доза, длительность
  • Контроль: срок повторного визита / обследования
  • При онкориске / red flag - маршрут в рекомендациях
  • Консультация: есть направление и связь с визитом

Формально - отказ ЦИСЗ

  • Визит completed, дата/время приёма
  • Витальные и антропометрия (если первичный приём)
  • Диагноз привязан к визиту
  • Composition - первый в пакете, дата документа

Protocol не подписывает и не отправляет данные в ЦИСЗ - только ориентир методслужбы по КП Минздрава и чек-лист FHIR. Не замена МЭЭ. Полная архитектура: architecture-kravira-fhir-mis.pdf · Нормативка: FHIR BY, Протокол МИС-ЦИСЗ v.1.4, программа испытаний МИС v.1.3-4.
