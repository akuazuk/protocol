# МО: отсутствие кода МКБ не дефект при наличии диагноза

Статус: **active**  
Дата: 2026-08-08  
Связано: `2026-08-06-mo-icd-full-document-search-v1.md`, `2026-08-08-mo-icd-dx-matching-pipeline-v3.md`

## Контекст

Ложное замечание `B_icd_invalid` («Код МКБ отсутствует или не соответствует
формату») на кейсах с текстом диагноза без кода (пример: «Острая рецидивирующая
анальная трещина.»).

Правило владельца:

1. **Нет кода МКБ, но есть формулировка диагноза** - не нарушение.
2. **Нет ни кода, ни диагноза** - дефект (документация / `A_missing_diagnosis`).
3. **Код указан, но битый формат** - по-прежнему замечание.

## Метрики

| | Было | Цель |
|--|------|------|
| `B_icd_invalid` при Dx без кода | P2 finding + штраф оси | нет finding, без штрафа |
| `B_icd_invalid` при битом коде | finding | finding |
| Нет Dx и нет кода | A_missing + иногда B_icd | A_missing; B_icd только если уместно |
