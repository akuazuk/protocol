# МО Аналитика: понятный план дашбордов и меню (v2)

Дата: 2026-08-09
Статус: **active**
Преемник: `2026-08-09-mo-dashboards-zones-first-v1.md` (archived - слишком технический)
Канон меню: это v2 + `2026-08-08-mo-analytics-ui-target-v2.md`

Простыми словами: методист заходит в МО Аналитику, слева видит короткое меню,
на экранах - только то, что помогает разобрать качество записей. Старые
«красивые» графики и лишние проценты убираем с первого экрана.

---

## 1. Что остаётся в голове у методиста

У каждой записи смотрим четыре вещи (не десять):

| Что | Смысл простыми словами | Когда «плохо» |
|--|--|--|
| **Оформление** | Заполнен ли осмотр как положено (жалобы, анамнез, осмотр…) | дыры в тексте МО |
| **Диагноз** | Есть ли диагноз и код, согласованы ли они | нет Dx / слабая опора |
| **План по протоколу** | Обследование и лечение по клиническому протоколу | только если протокол подобран; иначе «протокол не подобран», не «0%» |
| **Риск** | Опасные вещи (лекарства, красные флаги) | не процент, а «есть / нет» в очереди |

Отдельно (не путать с зоной «Диагноз»):

- **Чип МКБ** - нашлась ли формулировка в справочнике.
- **Итог разбора** - уже в карточке случая: что сказать врачу.
- **№55** - соответствие постановлению по роли (педиатр / ВОП…). Это проверка
  «по инструкции», не замена трёх зон. Показываем глубже, не вместо «Сегодня».

## 2. Левое меню - как будет

### 2.1 Видимые пункты (ровно 6)

Порядок сверху вниз. Имена только на русском.

```text
МО Аналитика
├─ Сегодня      ← стартовый экран дня
├─ Период       ← месяц / выбранные даты
├─ Очередь      ← что разобрать прямо сейчас
├─ Все случаи   ← поиск по всем записям
├─ Врачи        ← кто тянет качество вниз
└─ Отчёты       ← выгрузки
```

Внизу меню (не пункт списка): ссылка **«Кабинет методиста»** - как сейчас.

### 2.2 Что убрать из меню насовсем (не показывать)

Сейчас часть пунктов уже скрыта (`hidden`). В целевом виде их **нет в меню**:

| Пункт сейчас (скрыт или живой) | Решение |
|--|--|
| Безопасность | убрать; риск виден в Очереди и в разборе |
| Специальности | убрать; «куда смотреть» живёт внутри Периода |
| Диагнозы (дерево МКБ) | убрать |
| Качество данных | убрать с меню; свежесть данных - одна строка на Сегодня |
| Кабинет врача | убрать; expert уже уводит в МО |
| Журнал доступа | только внутри Отчётов или админки, не в основном меню |
| Настройки | не пункт меню; легенда зон - мелкая ссылка внизу сайдбара |

Итого слева: **6 рабочих кнопок + ссылка в кабинет**. Без групп «Мониторинг / Работа / Аналитика».

### 2.3 Фильтры сверху (на всех экранах одинаково)

Период · Филиал · Специальность · Врач.
По умолчанию только клинические приёмы (не процедуры «мимо» оценки).

## 3. Что будет на каждом экране

### 3.1 Сегодня

Зачем: «что делать сегодня».

**Будет:**

1. Одна строка сверху: сколько записей за день · сколько оценено · данные на какую дату.
2. Пять крупных плиток (клик открывает список):
   - Критично в очереди
   - Важно в очереди
   - Оформление плохо
   - Диагноз плохо
   - План по протоколу плохо
3. Таблица дня - кого разбирать (визит, врач, диагноз, раздел, причина).
4. Один простой график внизу: три линии за 2 недели (оформление / диагноз / план).

**Уберём с Сегодня:**

- воронку CRM
- heatmap
- четыре старые оси (документация / согласованность / безопасность / регуляторика) как главные KPI
- «итоговую оценку» как главный процент
- чек-лист №55 и таблицу «рубрика МЗ»
- Pareto замечаний
- длинный pipeline «полнота загрузки» как центр экрана

### 3.2 Период

Зачем: картина за месяц / диапазон.

**Будет:**

1. Те же пять плиток, но за выбранный период.
2. Тот же график трёх зон.
3. Блок **«Куда смотреть»** - таблица специальностей или врачей: у кого больше «плохо» по зонам → кнопка «Открыть случаи».

**Свёрнуто «Подробнее» (по клику, не на первом экране):**

- после готовности нового №55: средний % по постановлению + какие пункты чаще проваливаются;
- доли чипов МКБ (ок / нет / слабо);
- сколько записей с клиническими разрывами (жалоба vs осмотр и т.п.) - когда правила стабильны.

**Уберём с Периода (то, что сейчас шумит):**

- heatmap «специальность × глава МКБ»
- Pareto замечаний
- воронку месяца
- dual KPI «Рубрика МЗ»
- пустую / старую карточку «Соответствие №55» как главную
- рейтинг врачей со scatter «ожидание vs факт»

### 3.3 Очередь

Зачем: список на разбор здесь и сейчас.

**Будет:**

- приоритет (критично / важно)
- раздел (оформление / диагноз / план / риск)
- визит, пациент, дата, врач, диагноз
- три короткие оценки: в норме / слабо / плохо / протокол не подобран
- причина одной фразой
- статус разбора

**Не будет:** тикетов «просто потому что №55» или «слабо МКБ» без реальной проблемы; процентов в каждой клетке.

### 3.4 Все случаи

Зачем: найти любую запись.

**Будет по умолчанию:** визит · пациент · дата · врач · диагноз · МКБ-чип · история · оформление · диагноз · план · причина · статус.

**Спрятано в настройке колонок:** сводный индекс, старый №55, «полнота проверки», «надёжность».

### 3.5 Врачи

Зачем: кто тянет качество вниз.

**Будет:** таблица врач / специальность / число случаев / % плохо по трём зонам / сколько в очереди / «открыть случаи».
Один график полосами по выбранной зоне (оформление или диагноз или план).

**Не будет:** scatter и отдельной страницы «Специальности».

### 3.6 Отчёты

Как сейчас: выгрузки и служебные отчёты. Без новых тяжёлых графиков на главной.

### 3.7 Разбор случая (не пункт меню - открывается из списков)

Уже сделано и оставляем:

1. Три карточки зон
2. **Итог разбора** (что не так + что сказать врачу)
3. Список замечаний
4. Критерии методики
5. История и протоколы
6. Решение методиста

В самый низ «Служебное»: старые оси, CRM, пакеты обучения.
ИИ - только как черновик, не главная оценка.

## 4. Что убираем / что появляется - одной таблицей

| Было на виду | Станет |
|--|--|
| Много пунктов меню + скрытые «аналитические» страницы | 6 пунктов меню |
| Главный смысл = «итоговый %» | Главный смысл = три зоны + очередь |
| Рубрика МЗ + пустой №55 на Обзоре | убрать с первого экрана; №55 - в «Подробнее» Периода после нового scorer |
| Heatmap, Pareto, funnel на Периоде | убрать |
| Отдельные экраны Безопасность / Специальности / Диагнозы | нет в меню |
| В разборе каша блоков | зоны → итог разбора → замечания (уже в проде) |
| МКБ «слабо» путается с зоной Диагноз | отдельный чип + пояснение |

## 5. Как это стыкуется с другими работами (коротко)

| Где ещё идёт работа | Что делаем здесь |
|--|--|
| PR с новым расчётом №55 по роли | не рисуем UI №55, пока scorer не в `main`; потом - только в «Подробнее» Периода |
| Единый вход / пароли методиста | не трогаем в этой волне |
| Ночной LLM на GCE | не выносим ИИ-% на плитки Сегодня |
| Очередь «только точные сигналы» | сохраняем: №55 сам по себе не создаёт тикет |
| Чужие вкладки / грязный репозиторий | правки только из чистой ветки от `origin/main` |

Порядок работ:

1. Согласовать это меню и экраны (этот документ).
2. Почистить Сегодня и Период (убрать лишние графики и KPI).
3. Дождаться merge нового №55 → добавить свёрнутый блок на Период.
4. Потом - сводки по МКБ и клиническим разрывам в «Подробнее».

---

## 6. Как проверить, что получилось

Методист без обучения отвечает за 1-2 минуты:

1. Сколько критичного сегодня и куда кликнуть?
2. Плохо оформление, диагноз или план?
3. Какой врач / специальность тянет вниз за период?
4. В разборе: что сказать врачу (блок «Итог разбора»)?

Если для ответа нужен heatmap или «итоговый %» - план выполнен плохо.
