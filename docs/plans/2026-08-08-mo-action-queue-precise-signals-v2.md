# МО: очередь разбора по точным сигналам оценки (v2)

Статус: **active**  
Дата: 2026-08-08  
Преемник: `2026-08-08-mo-action-priority-formula-ru-v1.md` (архив по входу в очередь)

## Контекст

Очередь «Разбор» наполнялась любым finding `P0`/`P1`, из-за чего туда
попадали почти все `D_reg55_*` (нет слота диагноза и т.п.) при формуле 60-75%.
Задача: отбирать МО, которые **не соответствуют хорошей оценке**, по самым
точным детерминированным сигналам - не по ярлыку тяжести №55.

## Каталог сигналов (точность)

| Код | Точность | В очередь | Полоса |
|--|--|--|--|
| `C_red_flag`, `C_red_flag_unrouted` | высокая | да | Критично |
| `C_ddi` Major / sev P0-P1 | высокая | да | Важно / Критично |
| `C_high_alert_no_dose` | высокая | да | Важно |
| `C_nsaid_dup` | высокая | да | Важно |
| `B_dx_no_support`, `B_dx_absent` | высокая | да | Важно |
| `C_uncertainty_unrouted` | средняя | да | Важно |
| `D_reg55_*` | низкая для тикета | **нет** | только в карточке |
| `B_icd_*` | не тикет очереди | **нет** | карточка |
| `A_missing_*` | оформление | **нет** | карточка |
| `E_template_copy` | шумно | **нет** | карточка |
| shadow concordance / dir | shadow | **нет** | |

Формула % и №55 - справка в строке, не входной фильтр.
