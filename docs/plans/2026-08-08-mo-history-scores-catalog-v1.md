# МО: вернуть историю пациента + каталог всех оценок

Статус: **active**  
Дата: 2026-08-08

## Контекст

В разборе случая блок «История пациента» выглядит пропавшим: сырые tier на английском,
пустые полки без пояснения, `record.history_*` часто null, а повторная сборка после
identity lookup могла затирать бандл. Параллельно для редизайна дашбордов нужен
единый каталог всех видов оценок МО с методом.

## Решение

1. Force-rebuild истории после identity; не затирать хороший бандл пустым.
2. Синхронизировать `record.history_prior_n` / `history_tier` из live-бандла.
3. UI: RU-подписи tier, пояснение «как влияет на оценки», полки и коды всегда видны.
4. Документ `docs/methodist/mo-evaluation-catalog.md` - источник истины для дашбордов.

## Метрики

| | Было | Цель |
|--|--|--|
| История в разборе | «пропала» / 0 без пояснения | блок с RU tier + полки + usage |
| `record.history_*` в detail | часто null | = live bundle |
| Каталог оценок | разрозненные планы | один каталог всех scorers |
