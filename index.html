Поиск протоколов

Индекс рассчитан под сопоставление с формулировками диагноза и МКБ-10 в протоколах. При одних жалобах сначала нажмите «Подобрать коды МКБ», затем - «Найти протоколы».

Поиск в корпусе ведётся в основном по совпадению с диагнозом и кодами МКБ-10 в текстах протоколов. Если указаны только симптомы, сервис при полном поиске тоже пытается вывести коды, но надёжнее сначала нажать «Подобрать коды МКБ», проверить строку и затем «Найти протоколы».

Голосовой ввод

Текст попадёт в поле запроса выше. Распознавание в браузере; аудио на сервер не отправляется.

Сначала коды МКБ

Если в поле только жалобы без диагноза - подбор кодов перед поиском протоколов.

Распознавание в текст (предпросмотр)
Как устроен поиск

Отбор фрагментов PDF рассчитан на совпадение с диагнозом и кодами МКБ-10 в тексте протоколов. Краткий ответ - ориентир по документам, не установление диагноза и не замена очного приёма.

1
Укажите при необходимости контекст и рубрики. В поле запроса лучше сразу ввести диагноз и/или МКБ-10. Если есть только жалобы - нажмите «Подобрать коды МКБ», проверьте предложенные коды, при необходимости отредактируйте текст и затем «Найти протоколы».
2
В «Результат подбора» - список протоколов с оценкой близости (0-100%): технический ориентир для выбора PDF, не «вероятность диагноза». Даётся краткий разбор по запросу.
3
По желанию: дифференциальные гипотезы (кнопка «Искать протокол» подставляет выбранную строку в запрос) и шаблон консультативного заключения по развёрнутой выдержке - только черновик; нужна проверка и правка врачом.

Примеры (сначала диагноз/МКБ - точнее подбор)

J20.9 острый бронхит I10 эссенциальная гипертензия E11.9 сахарный диабет 2 типа жалобы → «Подобрать коды МКБ», затем поиск

Совет: на телефоне можно надиктовать в поле кнопкой «Надиктовать в поле» (слева под полем) - аудио на сервер не уходит.

Результат подбора

Главный раздел

Проверка консультативного заключения

PDF, TXT, DOCX, RTF, ODT, HTML → сверка с фрагментами клинических протоколов Минздрава РБ

Презентация MVP для руководствасхемы контура качества и дорожная карта

Выберите сразу до трёх файлов заключения в одном окне (PDF, TXT, DOCX, RTF, ODT, HTML и др.; несколько приёмов: удерживайте Ctrl или ⌘). Для PDF нужен текстовый слой, не только скан. Сервис объединит тексты, отберёт фрагменты протоколов и даст ориентировочную оценку (не МЭЭ и не юридическая экспертиза).

Жалобы и претензии. Расхождение между текстом заключения и протоколом часто становится предметом разбора случая. Инструмент помогает методслужбе и заведующему заранее увидеть слабые места в документации (критерии ниже 70%) - до эскалации, не вместо очной экспертизы.

Документ может содержать персональные данные - не передавайте через публичные незащищённые каналы без решения по ИБ.

Режим методиста. Система оценит КZ (этап 1), затем ИИ проверит, насколько верна эта оценка, и предложит правки для движка анализа - не список правок для врача.

Файлы не выбраны

Три КЗ за раз: в диалоге «Выбрать» отметьте до трёх файлов (Ctrl/⌘ + щелчок). Форматы: PDF, TXT, DOCX, RTF, ODT, HTML.
