## Контекст

Кейс `mo_1_test.pdf` (J45 + аллергический ринит + …): в МО Аналитика finding
`B_icd_name_weak_match` с «Ближе всего: Аллергический ринит… / Головная боль, score≈0.38»,
хотя формулировки есть в справочнике. Причина: весь длинный мультидиагноз сравнивался
с одним коротким `title_ru` → размытый score; короткий title «выигрывал» overlap.

Параллельно: в разборе случая критерии методики были спрятаны в `<details>` и без
краткого итога - методист не видел «разбор по критериям» как в ручном разборе агента.

## Что меняем

1. `split_diagnosis_phrases` + `best_combined_against_title` - max score по фразам.
2. Сид кандидатов из кодов в исходном тексте (title по J45 и т.п.).
3. `strip_icd_codes` нормализует кириллические формы (`Е 55.0`).
4. UI: блок «Разбор по критериям» - краткий список слабостей + полная таблица по зонам.
5. Маркеры факторов риска: семейная АГ / гиперхолестеринемия.
